### git commit message
| 種類 | 用途 | 例 |
|---|---|---|
| `feat` | 機能追加 | `feat: ACTに触覚入力を追加` |
| `fix` | バグ修正 | `fix: バッチサイズ1で出力形状が崩れる問題を修正` |
| `refactor` | 動作を変えないコード整理 | `refactor: 学習ループを関数に分割` |
| `docs` | 説明・文書の更新 | `docs: 学習の実行手順を追加` |
| `test` | テストの追加・修正 | `test: action chunkのpadding処理を検証` |
| `chore` | 依存関係や設定などの整備 | `chore: 不要な依存パッケージを削除` |
